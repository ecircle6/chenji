📋 分类筛选方案说明（替代 v2 的两行胶囊）

  • 1首页只保留一行快捷胶囊：把高频选项（关系 + 类型按实际数据出现）混编成一排横向滚动，点即筛、直觉操作，不需要理解「维度」概念；行尾「⋯ 更多筛选」进入完整面板。
  • 2完整筛选 = 底部弹出面板：面板内按维度分组（关系 / 类型 / 生肖…），组间可叠加（家人 ∩ 生日 ∩ 属虎），组内单选；顶部实时显示当前筛选摘要，可一键清除/重置。
  • 3配置驱动、天然可扩展：快捷胶囊与面板各组都由同一份「筛选维度配置列表」生成，新增维度（生肖、月份、自定义标签…）只是配置里加一组，UI 不用改结构、首页不会多出一行。
  • 4生肖维度已真实可行：birthday 表已有 birthYear 字段、ZodiacUtils 已能按年份算生肖，无需改数据库、无需迁移——面板加一组「按 birthYear 派生生肖」即完成。演示中「属狗 / 属兔 / 属鸡 / 属虎」即由此生成。
  • 5未来真正需要加字段的场景（如自定义标签/分组）：数据层做迁移，但 UI 层同样只是面板加一组配置——扩展成本被隔离在配置之后，首页布局永远只有一行。
  • 6状态同步：快捷胶囊与面板共享同一份筛选状态，面板确认后首页出现「已筛选」摘要胶囊；点快捷胶囊 = 单维快速切换（清掉其他维度），点「全部」/「清除」恢复。
  • 7与 v2 其余部分的关系：Hero 卡、紧凑卡片、底部双 tab、日历独立页、FAB 全部保持已确认的 v2 方案不变，本次只替换分类区。
  • 8✓ 实现层面（Kotlin）：HomeViewModel 增加 dims 状态（rel/type/zodiac 等 Map），HomeFilter 改为配置驱动的匹配函数；面板 = ModalBottomSheet；快捷行 = LazyRow。数据模型不动，测试适配。
