📋 首页改造说明（v2 · 底部导航版，对照参考稿适配辰记）

  • 1顶部栏保持现状：左上「辰记」标题，右上保留 🔍 搜索、⚙️ 设置入口（对应参考稿的齿轮按钮）。
  • 2新增日期 + 问候语行：仿参考稿顶部「8月16日 周六」+ 每日一句问候（现有文案池随机取，当天稳定不变）。
  • 3新增 Hero 聚焦卡（参考稿核心视觉）：展示最近一件大事 —— 名称 + 日期 + 52sp 超大倒计时，渐变底色随事件类型变化（生日暖橙 / 情侣紫 / 缅怀灰蓝 / 其他青，深色加深变体），右侧大 emoji 水印，点卡片直接进详情。取筛选后列表第一条（自动跳过已暂停），「就是今天」时文案切为今天横幅。
  • 4筛选保留两行、改胶囊样式：第一行关系标签（全部/家人/朋友/同事/其他）改为白色阴影胶囊，选中变深色实心；第二行类型胶囊（仅记录出现 2 种以上类型时显示）保留描边样式，叠加筛选逻辑不变。
  • 5列表头加计数：「即将到来」+「共 N 个日子」，随筛选/搜索实时变化。
  • 6卡片改紧凑式（参考稿样式）：左侧 4px 类型色条 + 圆角图标块（生日显示姓名首字、其余显示类型 emoji）+ 中间名称 + 事件类型标签 + 第二行小字「日期 · 关系」+ 右侧 26sp 大号倒计时；保留 📌 置顶、已暂停灰显徽标和「就是今天」横幅。移除「⏰ 提醒时刻」徽标（详情页仍显示）。
  • 7新增底部导航「首页 / 日历」双 tab（贴近参考稿，去掉「故事/我的」——辰记没有这两块内容，设置仍走右上角齿轮）：首页 = Hero + 筛选 + 列表；月历独立成「日历」页，一屏直达，保留翻月、农历小字、事件圆点、点日期弹窗进详情等全部现有能力；日历页显示全部记录（不受首页筛选影响）。原来的「列表 / 月历」分段切换删除。
  • 8FAB 保留（珊瑚渐变圆形 +，浮在底部导航上方），首页/日历两页都在、搜索时首页自动隐藏；空态（无记录/搜索无结果/筛选为空）三种页面保持不变。
  • 9深色模式完整适配（右框效果）：卡片、胶囊、Hero 渐变都有深色变体。
  • 10不改动的部分：HomeViewModel 筛选/排序/搜索逻辑、滑动删除、详情页、数据模型、备份、桌面小组件全部不动；无状态架构与 @Preview / UI 测试同步更新。
